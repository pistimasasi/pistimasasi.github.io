# Pişti Masası

Türkçe / Deutsch / English Pişti kart oyunu. Bilgisayara karşı ve online (Supabase) oynanabilir.

Oyna: https://pistimasasi.github.io/

- `index.html` – oyun
- `impressum.html`, `datenschutz.html` – yasal sayfalar
- `manifest.webmanifest`, `sw.js`, `icons/` – uygulama (PWA / Google Play) için
- `play-store/` – Google Play mağaza görselleri
